# EDUINO 컨트롤러 — 서비스 경로 검증 & 작업 리스트

> 목적: **블루투스 모듈이 있는 EDUINO 교구를 앱 하나로 모두 제어·체험**.
> 배포 대상: 공교육·사교육 현장 → 안정성·편의성·완성도 최우선.
> 분류: **① 블루투스 실습(공통)**, **② 교구 제어 = RC카 / 스마트팩토리 / 스마트홈 / 스마트팜**.

---

## 1. 현재 서비스 경로 (코드 검증 결과)

```
인트로(로고) → 모듈선택(HM-10/HC-06) → 홈
홈 ─ 블루투스 연결
   ─ AT 커맨드
   ─ 시리얼 통신 채팅
   ─ 블루투스 컨트롤러 → (조이스틱/방향/기울기/음성/LED, 자율주행=개발예정)
   ─ 미션 · 챌린지
   ─ 명령 ↔ 코드
   ─ (내 장비) 블루투스 모듈 / 에듀이노 교구(RC 3종) / 모터 포트 설정
```

### 검증에서 확인된 문제 (심각도)
| # | 항목 | 심각도 | 내용 |
|---|---|---|---|
| V1 | **구조가 RC 전용** | 🔴 높음 | 홈이 RC 기능 나열. "교구 제어" 컨셉(팩토리/홈/팜)과 안 맞음. 킷 능력 기반 재구성 필요 |
| V2 | **자동 재연결 없음** | 🔴 높음 | 앱 재실행·끊김 시 마지막 기기 재연결 없음 → 수업 중 매번 스캔 |
| V3 | **연결 유도 흐름 약함** | 🟠 중간 | 미연결 상태로도 기능 진입 가능(비활성). 첫 사용자 헷갈림 |
| V4 | **권한 거부 후 복구 없음** | 🟠 중간 | 블루투스/마이크 권한 거부 시 설정 이동(openAppSettings) 안내 없음 |
| V5 | **AT 실습의 교육 한계** | 🟠 중간 | 연결 후 AT는 모듈이 아닌 아두이노로 감(정상). 미연결 AT 실습 경로가 앱에 없음 |
| V6 | **모듈 변경 안내 없음** | 🟡 낮음 | 모듈 바꾸면 연결이 끊기는데 사용자 안내 없음 |
| V7 | **에러/로딩/토스트 비표준** | 🟡 낮음 | 화면마다 안내 방식 제각각 |
| V8 | **배포 필수요소 부재** | 🔴 높음 | 온보딩·설정·개인정보처리방침·권한설명·앱아이콘·스플래시·다국어 없음 |
| V9 | **디자인 일관성 편차** | 🟡 낮음 | 카드/여백/타이포가 화면마다 미세하게 다름 |

## 2. 목표 구조 (재설계안)

앱을 **킷 능력(capability) 기반**으로 일반화한다. "주행 앱"에서 "교구 제어 플랫폼"으로.

```
홈
├─ [공통] 블루투스 실습           ← 모든 교구 공통(통신 원리 학습)
│    ├ 연결
│    ├ 시리얼 통신 채팅
│    ├ AT 커맨드
│    └ 명령 ↔ 코드
│
└─ [교구 제어] 내 교구 선택 → 맞춤 제어판
     ├ RC카 (2휠/메탈/4휠)   : 조이스틱·방향·기울기·음성·LED·자율(예정)
     ├ 스마트 팩토리          : 컨베이어 ON/OFF·속도, 분류 서보, 센서
     ├ 스마트 홈             : 도어(서보)·조명·LCD 메시지·센서
     └ 스마트 팜 온실         : 팬·펌프·조명·온습도/토양 센서 모니터링
```

**핵심 개념: KitProfile 확장**
- 각 킷이 지원하는 **컨트롤 컴포넌트 목록**을 정의(예: `servo`, `relay`, `dcMotorPair`, `led`, `lcd`, `sensorPanel`, `conveyor`).
- 킷 선택 → 해당 컴포넌트로 제어판 자동 구성.
- 새 교구 추가 = 프로토콜 명령 + 컴포넌트 정의만 추가(화면 재사용).

## 3. 작업 리스트 (우선순위)

### P0 — 이번 스프린트: 블루투스 실습 + RC카 제어 보강 (지금 시작)
- [ ] **B1. 자동 재연결**: 마지막 연결 기기(주소) 저장 → 앱 시작/끊김 시 자동 재연결 + "재연결 중" 표시
- [ ] **B2. 연결 상태 전역 배너**: 모드 화면 상단 상태바를 탭하면 바로 연결/해제. 끊기면 눈에 띄게 안내
- [ ] **B3. 권한 흐름 개선**: 거부 시 `openAppSettings()` 유도, 블루투스 꺼짐 감지·켜기 안내
- [ ] **B4. 시리얼 채팅 보강**: 자동 스크롤·타임스탬프·보낸/받은 구분 강화, 예제 문장 프리셋, 로그 공유(실습 리포트)
- [ ] **B5. AT 커맨드 교육화**: "연결 상태 vs AT 모드" 다이어그램 안내, 응답 유무 설명, 모듈별 명령 세트 정리
- [ ] **R1. RC 주행 학습 화면**: 조이스틱/방향에 "지금 보내는 명령" 실시간 표시(교육), 속도 상한 설명 툴팁
- [ ] **R2. 방향버튼 완성도**: 8방향+회전 버튼 눌림 피드백·햅틱·명령 로그 연동
- [ ] **R3. 명령↔코드 매핑 확장**: RC 전 명령(DRV/MOV/SPD/STP/LED) + 실제 스케치 라인 연결, 복사 버튼
- [ ] **R4. 실기기 검증 체크리스트**(아래 5장) 기반 QA 후 이슈 수정

### P1 — 구조 재설계 (교구 제어 플랫폼화)
- [ ] **S1. 홈 재구성**: [블루투스 실습] / [교구 제어] 2분류 카드 구조
- [ ] **S2. KitProfile 능력 모델** 도입(컨트롤 컴포넌트 목록)
- [ ] **S3. 제어판 동적 구성**: 킷 선택 → 컴포넌트 기반 화면 자동 렌더
- [ ] **S4. 프로토콜 확장**: 서보(`SRV:`), 릴레이/액추에이터(`ACT:`), LCD(`LCD:`), 센서요청/응답 등 교구 공통 명령 정의
- [ ] **S5. 신규 교구 3종 추가**: 스마트팩토리/홈/팜 프로파일·제어판·펌웨어 예제·실사진 슬롯

### P2 — 배포 준비 (스토어 심사·현장 보급)
- [ ] **D1. 온보딩** 3~4장(모듈 고르기→페어링→연결→체험)
- [ ] **D2. 설정 화면**: 앱 버전·도움말·글자 크기·문의·오픈소스 라이선스
- [ ] **D3. 개인정보 처리방침 + 권한 설명**(블루투스/마이크) — 심사 필수
- [ ] **D4. 다국어(한/영)** i18n 구조
- [ ] **D5. 네이티브 앱아이콘·스플래시·번들ID·버전/빌드넘버 체계**
- [ ] **D6. 스토어 자산**: 스크린샷·설명·키워드(교육 카테고리)
- [ ] **D7. 접근성**: 색 대비(색약)·터치 타깃 48dp·글자 크기 대응

### P3 — 완성도/차별화
- [ ] **Q1. 디자인 시스템 통일**: 카드/여백/타이포/토스트/로딩 컴포넌트 표준화
- [ ] **Q2. 매크로 녹화·재생**(주행/제어 시퀀스)
- [ ] **Q3. 실시간 센서 그래프**(거리·온습도 등)
- [ ] **Q4. 차시/커리큘럼 QR 연동**(eduino.kr)
- [ ] **Q5. 미션 확장**(배지·베스트·여러 대)

## 4. 신규 교구 제어 설계 메모 (S5 참고)

| 교구 | 주요 액추에이터 | 센서 | 앱 제어 컴포넌트(안) |
|---|---|---|---|
| 스마트 팩토리 | 컨베이어 DC모터, 분류 서보 | 물체감지 | 컨베이어 ON/OFF·속도, 서보 각도, 감지 로그 |
| 스마트 홈 | 도어 서보, 조명(LED), LCD | 조도/인체 | 도어 열기/닫기, 조명 토글, LCD 메시지 전송, 센서 표시 |
| 스마트 팜 온실 | 팬, 워터펌프, 조명 | 온습도, 토양수분 | 팬/펌프/조명 토글, 자동/수동, 센서 실시간 그래프 |

→ 공통 명령 세트(`SRV`/`ACT`/`LCD`/센서 텔레메트리)로 추상화하면 RC와 같은 아키텍처로 흡수 가능.

## 5. 실기기 검증 체크리스트 (QA)

담당자/개발자가 실기기에서 체크(안드로이드, HC-06 & HM-10 각각):
- [ ] 인트로 → 모듈선택 → 홈 진입 정상
- [ ] HC-06: 페어링(1234) 후 목록 노출·연결·유지
- [ ] HM-10: 스캔·연결·유지
- [ ] 재진입/백그라운드 복귀 시 연결 상태 정확
- [ ] 시리얼 채팅 송수신(앱↔PC 시리얼 모니터)
- [ ] 방향버튼 8방향+회전 주행
- [ ] 조이스틱 주행 + DRV 값 표시, 약한 입력에도 이동(MIN_PWM)
- [ ] 속도 상한 슬라이더 반영
- [ ] LED 13번 핀 ON/OFF
- [ ] 기울기/음성 권한 허용 후 동작
- [ ] 연결 끊김 시 즉시 정지(안전)
- [ ] 종료/재실행 후 재연결 흐름

> 발견 이슈는 이 문서에 기록 → 우선순위대로 수정.
