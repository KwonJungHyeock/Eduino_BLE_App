# EDUINO RC 컨트롤러 — 시연 가이드 (담당자 시연용)

## 0. 준비물
- 안드로이드 폰/태블릿 (앱 설치)
- 2휠 RC카 (HC-06 + Adafruit Motor Shield, 왼쪽 M1 / 오른쪽 M4)
- PC (아두이노 IDE, 스케치 업로드용 · 시리얼 채팅 데모용)
- USB 케이블

## 1. 앱 설치 (QR)
- QR 스캔 → `app-debug.apk` 다운로드 → 설치 (출처 알 수 없는 앱 허용)
- 직접 링크: https://github.com/KwonJungHyeock/Eduino_BLE_App/releases/latest/download/app-debug.apk

## 2. 블루투스 페어링 (최초 1회)
- 폰 **설정 → 블루투스** → HC-06 페어링 (PIN `1234`)

## 3. 시연에 쓰는 스케치는 2개
| 데모 | 업로드할 스케치 |
|---|---|
| **시리얼 통신 채팅** (보이는 통신) | `firmware/serial_chat.ino` |
| **그 외 전부** (주행·LED·기울기·음성·자율주행) | `firmware/eduino_all_in_one.ino` |

> 두 데모를 모두 보여줄 거면, 채팅 먼저 → 스케치 교체 → 나머지 순서가 자연스럽습니다.

### 배선 (all_in_one 기준, 필요시 스케치 상단 핀 수정)
- HC-06: A5(RX)←HC-06 TX, A4(TX)→HC-06 RX, 9600
- 모터: 왼쪽 M1, 오른쪽 M4
- LED: D13
- 초음파: TRIG=A0, ECHO=A1  (`ENABLE_ULTRASONIC 1`)
- IR 라인센서: L=A2, C=A3, R=D2  (2휠/4휠은 `ENABLE_LINE 1`, 메탈은 0)

## 4. 추천 시연 순서 (스토리)

### ① 연결 — "블루투스 원리"
- 앱 실행 → 인트로(로고) → **HC-06 선택** → 홈
- **블루투스 연결** → 목록에서 HC-06 → 연결됨
- 포인트: "폰이 무선으로 로봇과 연결됩니다."

### ② 시리얼 통신 채팅 — "보이는 통신" (교육 핵심)
- 보드에 `serial_chat.ino` 업로드, PC에서 **시리얼 모니터(9600)** 열기
- 앱 **시리얼 통신 채팅**에서 글자 입력 → PC 시리얼 모니터에 `[App -> Arduino]` 로 뜸
- PC 시리얼 모니터에 입력 → 앱에 수신 말풍선
- 포인트: "오가는 데이터가 눈에 보입니다. 이게 통신 교육 교보재."

### ③ 주행 — 방향버튼 & 조이스틱
- 보드에 `eduino_all_in_one.ino` 업로드 (여기서부터 이 스케치)
- **블루투스 컨트롤러 → 방향 버튼**: 8방향 + 좌/우 회전
- **조이스틱**: 아날로그 주행, HUD 에 실시간 `DRV` 값·속도 게이지 표시
- 포인트: "버튼은 MOV, 조이스틱은 DRV 명령. 속도 상한 슬라이더로 안전 제어."

### ④ 부가 제어 — 기울기 · 음성 · LED
- **기울기**: 기기를 기울여 주행 (수평 맞추기 버튼으로 기준 잡기)
- **음성**: 마이크 버튼 → "전진", "정지", "왼쪽", "불 켜"
- **LED**: ON/OFF + 프리셋 컬러

### ⑤ 자율주행·실험 — 차별화 포인트 (강조)
- **블루투스 컨트롤러 → 자율주행·실험** → 상단 **자율주행** 토글
- 초음파 **거리 게이지**가 실시간으로 변함, 장애물 임계거리·자율 속도 **슬라이더**를 움직이면
  → **코드 재업로드 없이** 로봇 행동이 즉시 바뀜
- 포인트: "조종이 아니라 **자율주행을 실험**하는 앱. 값을 바꾸면 로봇이 달라집니다."

### ⑥ 미션 — 랩타임
- **미션 · 챌린지**: 시작 → 코스 주행 → 기록 종료 → 개인 베스트 갱신

### ⑦ 명령 ↔ 코드 — "코딩 교육 연결"
- **명령 ↔ 코드** 화면: "이 동작 = 이 아두이노 코드" 를 나란히 보여줌
- 포인트: "앱 조작이 실제 코드와 어떻게 연결되는지 학습."

## 5. 자주 나오는 상황
- **안 움직임** → all_in_one 스케치 업로드했는지, 모터 배선(M1/M4) 확인. 모터 반대로 돌면 스케치의 FORWARD/BACKWARD 또는 배선 극성 교체.
- **거리/라인 값이 안 뜸** → 초음파/IR 배선과 스케치 상단 `ENABLE_*` 확인.
- **음성/기울기 안 됨** → 첫 사용 시 마이크/센서 권한 허용.
- **연결이 자꾸 끊김** → HC-06 전원(배터리) 확인, 페어링 상태 확인.
