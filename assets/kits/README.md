# 키트 제품 실사진 에셋 슬롯 (§6.4)

이 폴더는 **EDUINO 3종 제품의 실제 제품 사진/렌더**를 넣는 자리다.
"AI로 찍어낸 도형이미지"를 배제하고, 자사 제품을 직접 소유한다는 점을 히어로 비주얼로 활용한다.

## 파일 규칙 (코드가 참조하는 경로)
| 키트 | 파일명 | 비고 |
|---|---|---|
| 2휠 RC카 (H-10) | `two_wheel.png` | IR 라인센서 있음 |
| 메탈 RC카 | `metal.png` | IR 라인센서 없음 |
| 4휠 스마트카 | `metal.png` → `four_wheel.png` | IR 라인센서 있음 |

- 권장 해상도: 1200×900 이상, 배경 투명(PNG) 또는 다크 배경에 어울리는 컷.
- 파일이 없어도 앱은 동작한다(키트 카드가 아이콘 플레이스홀더로 대체). 실사진을 넣으면 자동 반영.
