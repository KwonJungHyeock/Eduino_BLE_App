# 키트 제품 실사진 에셋 슬롯 (§6.4)

이 폴더는 **EDUINO 3종 제품의 실제 제품 사진/렌더**를 넣는 자리다.
"AI로 찍어낸 도형이미지"를 배제하고, 자사 제품을 직접 소유한다는 점을 히어로 비주얼로 활용한다.

## 파일 규칙 (코드가 참조하는 경로)
| 교구 | 파일명 | 특징 |
|---|---|---|
| 2휠 RC카 (H-10) | `two_wheel.jpg` | 투명 아크릴 2륜 · IR 라인센서 있음 |
| 4휠 스마트카 | `four_wheel.jpg` | 검정 4륜 · IR 라인센서 있음 |
| 메탈 RC카 | `metal.png` | 메탈(퍼플) 섀시 · IR 라인센서 없음 |
| 스마트 팩토리 | `smart_factory.png` | 컨베이어·분류 서보 |
| 스마트 홈 키트 | `smart_home.png` | 도어 서보·조명·LCD |
| 스마트 팜 온실 | `smart_farm.png` | 팬·펌프·조명·센서 |

- 권장: 정사각(1:1)에 가까운 컷, 배경 투명(PNG) 또는 밝은 배경. 카드에서 `contain` 으로 표시되어 잘리지 않는다.
- 파일이 없어도 앱은 동작한다(아이콘 플레이스홀더로 대체). 실사진을 넣으면 자동 반영.
- GitHub 웹 업로드: 저장소 → `assets/kits/` → **Add file → Upload files** → 위 파일명으로 업로드 → Commit.
